# DSA Library

A growing collection of **Data Structures and Algorithms problems, approaches, and solutions** that I solve along the way.

The problems are collected from various competitive programming and coding platforms, with a focus on understanding different approaches and improving problem-solving skills.

## Platforms

* [LeetCode](https://leetcode.com/)
* [GeeksforGeeks](https://www.geeksforgeeks.org/)
* [Codeforces](https://codeforces.com/)
* [AtCoder](https://atcoder.jp/)
* And other coding platforms

## What You'll Find

For each problem, this repository may include:

* Problem statement / reference
* Initial or brute-force approach
* Improved approaches
* Optimal solution
* Time and space complexity
* Important observations and patterns
* Notes and learnings

The goal is not just to collect solutions, but to keep track of **how the solution was approached and improved**.


## Progress

This is a **work in progress** and will continue to grow as I solve more problems.

> One problem at a time. One approach at a time. Better problem solving over time.

## Languages

Most solutions are written in **C++**.

More languages may be added when needed.
